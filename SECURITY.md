# Безопасность

TenderBomb предназначен для доверенной локальной сети. Встроенный HTTP-сервер не рассчитан на открытое размещение в интернете.

- HTTP не шифрует трафик; локальные файлы состояния не зашифрованы приложением.
- Не публикуйте файл рекордов, резервные копии, журналы, идентификаторы профилей, токены сессий и реальные адреса внутренней сети.
- Для примеров в issues и PR используйте вымышленные данные; проверяйте скриншоты перед публикацией.
- Перед обновлением остановите сервер и сохраните резервную копию локального состояния. Не запускайте два сервера с одним хранилищем.

## Сообщить об уязвимости

Не публикуйте детали эксплуатации, секреты и данные игроков в публичных issues.

Если на вкладке Security доступна кнопка **Report a vulnerability**, отправьте закрытый отчёт через неё. Если кнопки нет, попросите владельца организовать закрытый канал, не раскрывая технических деталей публично. Этот документ не означает, что приватные отчёты включены.

В закрытом отчёте укажите версию или коммит, шаги воспроизведения на вымышленных данных и возможные последствия.

Исправления следует проверять на актуальной версии из основной ветки. Гарантированные сроки ответа и поддержка старых версий не установлены.
